# Hide Enterprise Modules

This module customizes the Apps menu to hide enterprise modules by default while preserving the ability to group by enterprise status.

## Features

- Hides modules with `to_buy = True` from the default Apps view
- Adds filter options to show/hide enterprise modules
- Preserves the "Group By Enterprise Module" functionality
- Auto-installs when the module is available

## Usage

After installation, the Apps menu will only show community modules by default. You can:

1. Use "Show Enterprise" filter to see enterprise modules
2. Use "Hide Enterprise" filter to hide them again  
3. Group by "Odoo Enterprise Module" to see the distinction

This provides a clean Apps interface focused on available community modules while maintaining enterprise module visibility when needed.
